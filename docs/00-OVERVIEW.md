# Trotter - Race Timing App

## Vision
**Trotter** is a simple, pocket-sized race timing solution that replaces expensive timing equipment. Time any race (5k, marathon, etc.) directly from your phone with an intuitive, easy-to-use interface.

## Core Concept
- **Local-first**: All data stored on device initially
- **Simple & Fast**: Designed for chaotic finish line scenarios
- **Future-ready**: Built to expand to server-side support and multi-user collaboration later

## App Name
**Trotter** - A playful reference to "trotting along" in running

## Target Users
- Race organizers (small to medium events)
- Running clubs
- School events
- Community races
- Anyone needing simple, reliable race timing

## Platform Strategy
- **Primary**: iOS (React Native)
- **Secondary**: Android (comes naturally with React Native)
- **Tech Stack**: React Native with Expo (local development, free)

---

## Key Differentiators from Old App
1. **Event Management**: Multiple events, not just one race at a time
2. **Better UX**: Split-view finisher tracking for chaotic finish lines
3. **Modern Design**: Card-based UI, intuitive navigation
4. **Robust Data**: Better handling of edge cases and manual adjustments
5. **Future-Proof**: Architecture ready for cloud sync and multi-user
