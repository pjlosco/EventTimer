# Age Brackets — Suggestions & Customization

Age brackets are **suggestions only**. Users customize per event. Below are common standards from research (USATF, NYRR, BAA, typical 5k races).

---

## Youth (Kids)

**USATF-style (common for youth track/cross country):**
| Division | Ages |
|----------|------|
| 8 & Under | 0–8 |
| 9–10 | 9–10 |
| 11–12 | 11–12 |
| 13–14 | 13–14 |
| 15–16 | 15–16 |
| 17–18 | 17–18 |

**Younger kids (often separate “dash” events):**
| Division | Ages |
|----------|------|
| 3–4 | 3–4 |
| 5–6 | 5–6 |
| 7–9 | 7–9 |
| 10–12 | 10–12 |

## App Behavior

- **Defaults**: Ship 1–2 preset schemes (e.g. “Youth”, “Adult 5-year”, “Adult 10-year”) as **suggestions**.
- **Custom**: User defines their own brackets (e.g. “0–19, 20–29, 30–39, …” or event-specific).
- **Storage**: Store custom brackets per event (or per event type), not globally.
- **Results**: Filter/list results by selected age group. Place within group optional.

We’ll define the exact UI and data format when we implement Results.
